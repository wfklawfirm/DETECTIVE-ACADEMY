# أَثَر | ATHAR

منصة عربية أولاً للألغاز التحقيقية القائمة على الأدلة (الأعمار 16–22). هذا المستودع **نموذج عملي قابل للتشغيل** (شريحة رأسية احترافية)، وليس منصة جاهزة تجارياً. اقرأ `docs/KNOWN_LIMITATIONS.md` قبل أي استنتاج.

## ما الموجود فعلاً
- محرك لعب خادمي («الحقيقة أولاً»): الحقيقة المرجعية للقضية لا تغادر الخادم قبل الإغلاق، ولا يولّدها نموذج لغوي أثناء اللعب.
- قضيتان أصليتان: `c000` تمهيدية «دفتر المختبر الضائع»، و`c001` القضية الرئيسية «الرصد الأخير» (مسارا إثبات مستقلان، مختبر توحيد التوقيت).
- واجهة عربية RTL للجوال أولاً: ملف، أدلة، شخصيات، لوحة فرضيات، خط زمني ومختبر، مفكرة وتلميحات، استنتاج نهائي، ملخص وتقييم، اختبار نقل.
- **تلميحات دخول** (hooks) في كل دخول: تلميح واحد خالٍ من الحرق، بدون ضغط خسارة، مع «وضع هادئ».
- أكاديمية: 6 مسارات × 3 دروس + لغز يومي.
- استوديو داخلي: حفظ نسخ، فحص جودة وتسرّب، ست/سبع بوابات مراجعة مربوطة ببصمة المحتوى، قاعدة العينين، نشر، طلبات مراجعة الحجج، بلاغات، سجل تدقيق.
- اختبارات: وحدات (vitest) + متصفح (Playwright + axe). النتائج الصادقة في `docs/TEST_REPORT.md`.

## التشغيل محلياً
```bash
npm install
npm run setup      # ينشئ .env.local بسر عشوائي وكلمة مرور مدير (تُطبع مرة واحدة)
npm run migrate && npm run seed
npm run dev        # http://localhost:3100
```
فحص شامل: `npm run verify` (أنواع + فحص القضايا + اختبارات الوحدات)، ثم `npm run build && npm run test:e2e`.

## الخريطة
`content/cases` (قضايا: core + ui + scoring) · `content/hooks` · `content/tracks` · `src/engine` (محرك نقي بلا إدخال/إخراج) · `src/server` (قاعدة بيانات، مصادقة، لعب) · `src/app` (واجهة وواجهات API) · `migrations` · `docs`.

## حدود يجب معرفتها
المحتوى «تجريبي» ولم يخضع لمراجعة خبراء حقيقية؛ لا اختبار مستخدمين حقيقيين؛ لا مزوّد ذكاء اصطناعي خارجي موصول؛ بوابة العمر ذاتية الإفصاح؛ محدّد المعدّل داخل الذاكرة (نسخة واحدة). التفاصيل في `docs/KNOWN_LIMITATIONS.md`.
