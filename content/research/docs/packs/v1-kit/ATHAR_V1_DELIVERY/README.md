# ATHAR / أَثَر — v1.0 Delivery

هذه حزمة تنفيذية أولية فوق بحث سابق: نموذج محلي تفاعلي كامل المسار لقضية واحدة، ووثائق منتج، وبوابات نشر، وبرومبت تحويل إلى تطبيق إنتاجي، وتسع حبكات/قضايا قيد التطوير.

## تشغيل فوري
افتح `prototype/index.html` في متصفح حديث دون اتصال إنترنت؛ يتضمن جميع الواجهة والبيانات والقواعد. لا يوجد نموذج ذكاء اصطناعي متصل، ولا تخزين على خادم، ولا ادعاء بأن التجربة العلمية أو التربوية تم اعتمادها.

## حدود النتائج
- سيناريو خيالي بأسماء وسجلات أصلية مكتوبة لهذا المشروع.
- التقييم النصي heuristic ويكافئ علامات شكلية في التعليل، وليس حكماً موضوعياً متيناً على جودة الاستدلال: يستلزم تحسيناً وفحصاً بشرياً قبل إطلاق عام.
- لم تجر مقابلات مع مستخدمين ولا اختبارات صلاحية تربوية ولا تدقيق علمي خارجي.
- الملفات التسعة `docs/05_CASE_*.md` مواد تحريرية أولية، وليست منتجات مكتملة.

## الشجرة
- `prototype/index.html`: نموذج لعب مستقل.
- `docs/PRODUCT_BLUEPRINT.md`: قرار المنتج والشرائح ومراحل النمو.
- `docs/EDITORIAL_AND_SCIENCE_GATE.md`: بوابات الجودة والحقوق والسلامة.
- `docs/CLAUDE_BUILD_PROMPT.md`: برومبت التنفيذ التقني.
- `docs/05_CASE_*.md`: تسع قضايا سابقة.
- `qa/prototype_checks.json`: نتائج فحوصات آلية بنيوية أولية.

## قرار الإطلاق
NO PUBLIC LAUNCH حتى المراجعة والاختبارات البشرية ومطابقة متطلبات الخصوصية وحقوق الأصول. CONDITIONAL GO لاختبار نموذج داخلي مع مستخدمين بالغين أولاً.
