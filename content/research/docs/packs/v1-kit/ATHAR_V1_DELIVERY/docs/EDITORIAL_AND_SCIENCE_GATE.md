# ATHAR — Publishing Gates

## Gate A: أصل القصة والحقوق
- سجل أصل كل عنصر: نص، صورة، صوت، شخصية، اسم، مرجع.
- لا إعادة استخدام لنصوص محمية أو ترجمتها دون حق. الملك العام يُراجع حسب البلد والطبعة.
- لا «قصة مستوحاة» تنقل بنية مميزة وعناصر محمية نقلاً قريباً.

## Gate B: العدالة والمنطق
- يُكتب الحل النهائي والجدول الزمني قبل الحوار.
- كل قرينة أساسية متاحة عبر مسار لعب منطقي قبل النهاية.
- لا تعتمد الحقيقة على التخمين في كلمة سر أو مصادفة غير ممهدة.
- يستطيع مختبر مستقل حل القضية دون معرفة المؤلف.
- اختبار حالات عدم كفاية الدليل والتفسيرات البديلة.

## Gate C: الدقة العلمية
- لا تخلط بين الأدلة الجنائية والطب الشرعي.
- أي قياس له وحدة وسياق وعدم يقين.
- تمنع الاستنتاجات القطعية من دليل احتمالي.
- مراجعة مواد NIST/OSAC وغيرها حسب تخصصها وحالة إصدارها، وليست شهادات اعتماد للمنتج.
- تحقق مستقل من تحويل المناطق الزمنية والتواريخ.

## Gate D: الصلاحية التربوية
- مهارة محددة وسلوك مرصود لكل تجربة.
- لا استنتاج بأن المستخدم «ذكي» بسبب إجابة صحيحة.
- لا تعاقب المراجعة المبررة للرأي.
- تساوي فرص اللهجات والقراءة والقدرة اللغوية.
- اختبار سؤال نقل المهارة بمهمة غير مطابقة.

## Gate E: السلامة والخصوصية
- سن البداية المستهدف 16؛ التعامل مع القاصرين يخضع لمتطلبات البلد.
- لا صور صادمة أو تفصيل إجراءات مؤذية أو أساليب إخفاء أدلة.
- لا تتبع بيانات شخصية لا ضرورة لها.
- عرض واضح لطبيعة المحاكاة الخيالية وحدودها.

## Gate F: أداء المنتج
- تجارب الهاتف والكمبيوتر، اتجاه RTL، إمكانية لوحة المفاتيح والقراءة.
- اختبارات حفظ الحالة أو بيان عدم حفظها بوضوح.
- اختبارات ضغط JSON وأسماء الأدلة والترابط.
- اختبار fallback عند تعطل أي نموذج AI؛ لا تعليق لتجربة كاملة.
