# إطار التعلّم

**المبادئ:** التعلّم بالفعل (مهمة قبل شرح)، التغذية الراجعة المعلَّلة بالأدلة، المعايرة (ثقة تتبع الدليل)، مراجعة الرأي بوصفها مهارة، النقل إلى سياق جديد، تقليل العبء المعرفي (أدلة تظهر تدريجياً، تلميحات مدرَّجة).

**المسارات:** A الملاحظة · B المنطق والاستنتاج · C الأدلة والعلوم الجنائية · D الاستدلال التحقيقي · E الحقيقة الرقمية والتحقق · F إتقان الألغاز المتقدمة. لكل مسار 3 دروس قصيرة (3–7 دقائق) في `content/tracks/tracks.json`، كل درس: فكرة، مثال محلول، خطأ شائع، سؤال تطبيقي، وربط بقضية عند وجوده. المسار F حالياً دروسه تمهيدية لأن المحتوى المتقدم يحتاج قضايا أكثر.

**ربط المهارات:** كل قضية تعرّف `skills` (معرّفات KO من مكتبة المعرفة، محفوظة في `content/knowledge/ko_names.json`) وتغذي «مهاراتي» بمستوى 0–4 مبدئي مشتق (لا يُخزَّن).

**قيود:** لا ادعاء بأن الدروس حُكّمت تربوياً. اللغة المستهدفة فصحى مبسطة.
