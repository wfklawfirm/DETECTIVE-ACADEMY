# الأمان والخصوصية

## ما نُفِّذ (ومُختبر في `tests/unit/security.test.ts` و`tests/e2e`)
| الضابط | التنفيذ |
|---|---|
| الحقيقة المخفية خادمياً | `projectView` هو الخارج الوحيد؛ `forbiddenKeysIn` يفحص المفاتيح المحظورة في كل عرض؛ فحص تسرّب ساكن (`staticLeakScan`) على القضايا والتلميحات |
| كلمات المرور | scrypt مع ملح؛ رفض القصيرة والشائعة؛ عمل متساوٍ تقريباً لمستخدم غير موجود |
| الجلسات | معرّف عشوائي؛ نخزّن SHA-256 له؛ كعكة httpOnly وSameSite=Lax (+Secure في الإنتاج) |
| CSRF | `assertMutation`: فحص Origin/Content-Type للطلبات المغيِّرة |
| معدّل الطلبات | محدّد نافذة ثابتة لكل IP/مفتاح + حدود خاصة للدخول (8/15 دقيقة) والتسجيل (5/ساعة) |
| RBAC | `requireRole`؛ الاستوديو للمحررين/المراجعين/المدير؛ النشر للمدير؛ قاعدة العينين (الكاتب لا يعتمد ولا ينشر) |
| سلامة الحالة | رمز HMAC بغرض محدّد؛ يُرفض أي تعديل أو رمز قضية أخرى |
| الإدخال | zod على كل عملية؛ حدود حجم الجسم؛ حدود حقول المختبر |
| ترويسات | CSP، X-Frame-Options، nosniff، Referrer-Policy، Permissions-Policy (`next.config.ts`) |
| حقن التعليمات | لا مسار يمرّر نص اللاعب إلى نموذج؛ `guardGenerated` جاهز للمستقبل |
| تقليل البيانات | لا تاريخ ميلاد ولا اسم حقيقي؛ فئة عمرية فقط؛ IP مملّح مجزّأ |
| المراهقون | 16–17 لا حساب لهم ولا تخزين خادمي؛ لا ضغط خسارة؛ وضع هادئ؛ محتوى بلا عنف تفصيلي |
| الحذف | حذف الحساب بكلمة المرور والتأكيد؛ CASCADE للحالات |

## حدود صريحة
1. بوابة العمر **ذاتية الإفصاح** وليست تحققاً من الهوية.
2. المحدّد داخل الذاكرة: يصلح لنسخة واحدة فقط؛ للإنتاج المتعدد يلزم مخزن مشترك.
3. CSP يسمح بـ `unsafe-inline`/`unsafe-eval` (متطلبات Next في هذه النسخة)؛ تشديده بنونس مؤجَّل.
4. لا استرجاع كلمة مرور ولا تحقق بريد ولا 2FA بعد.
5. لا فحص اختراق خارجي ولا مراجعة أمنية مستقلة.
6. نظام الأسرار: `ATHAR_SECRET` في `.env.local`؛ تدويره يبطل رموز الحالة الموجودة.

## شرط نشر للذكاء الاصطناعي في الحوار
قبل ربط مزوّد توليدي: مراجعة قانونية لكل بلد مستهدف (قيود/تراخيص تخص أنظمة الحوار الآلي في بعض الدول العربية)، وتفعيل `guardGenerated` إلزامياً مع الرجوع للمزوّد المحلي عند الفشل، وسقف تكلفة لكل جلسة. لم يتحقق من القوانين المحلية ضمن هذه النسخة؛ تُعامل كبوابة نشر وليست ادعاءً.
