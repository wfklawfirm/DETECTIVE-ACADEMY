# رحلات المستخدم

1. **الزائر الجديد (16+):** يصل → بوابة العمر → تلميح دخول → «افتح أول ملف» → رسالة مجهولة (3 أسطر) → دفتر المختبر الضائع (12 د) → ملخص وتقييم مبدئي → عرض إنشاء حساب (للبالغين) أو متابعة كضيف.
2. **العائد:** يدخل `/home` → تلميح يذكر ملفه المفتوح (ودون ذنب أو عدّاد) → «تابع التحقيق».
3. **المحقق في «الرصد الأخير»:** يقرأ الملف → يلاحظ تعارض 21:10 مقابل 00:06 → المختبر (فرق منطقة + انحراف) → يتوافق التوقيت → مسار الإثبات (إما ترويسات + محادثة + استبعاد بديل، أو نتيجة المختبر + نشرة + سجل الجلسة) → استنتاج بثقة معايَرة وحدود → ملخص.
4. **المتعلم عبر الأكاديمية:** درس → مثال محلول → سؤال → «طبّق في قضية».
5. **المحرر/المراجع:** تسجيل دخول → استوديو → نسخ + حالة QA → اعتماد بوابات (ليس كاتب النسخة) → المدير ينشر.
6. **من يطلب مراجعة بشرية:** يرسل حجته مع الاستنتاج → رمز → يعود لاحقاً إلى `/review/<code>`.
7. **من يريد حذف بياناته:** حسابه → حذف بكلمة المرور؛ أو مسح بيانات الموقع للجهاز.
