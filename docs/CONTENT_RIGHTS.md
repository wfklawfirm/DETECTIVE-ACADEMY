# حقوق المحتوى

- **القصص والشخصيات:** أصلية كلياً من تأليف هذه الجلسة؛ لا استنساخ لألعاب أو أغلفة كتب أو شخصيات محمية. فحص آلي بسيط يمنع أسماء محققين مشهورين في القضايا (`tests/unit/cases.test.ts`)؛ وهو ليس فحص تشابه شاملاً.
- **المعرفة الجنائية:** الكتب المرجعية في مجلد المستخدم محمية بحقوق النشر؛ استُخلصت منها **أفكار على مستوى المفهوم فقط** ولا نصوص منقولة.
- **الأسماء:** «أثر/ATHAR» تصادمت مع أسماء قائمة في البحث؛ لم يُجرَ تدقيق علامة تجارية (القرار D12). «مرصد وادي النجوم» خيالي.
- **الخطوط:** Amiri، IBM Plex Sans Arabic، IBM Plex Mono، Reem Kufi عبر Fontsource (رخص OFL)؛ تُراجع الرخص قبل الإنتاج.
- **الصور/الصوت:** لا أصول جاهزة مستخدمة؛ لم تُفحص أصول المجلد.
- **ما يحتاج مراجعة قانونية:** شروط الاستخدام، سياسة الخصوصية بحسب كل بلد، وأي استخدام لاحق لنماذج توليدية.
