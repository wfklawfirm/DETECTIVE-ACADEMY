## ماذا بعد (بالأولوية)
1. تحكيم خبراء لـ c000/c001 ثم تشغيل البوابات.
2. تجربة 8–15 متعلماً مع ملاحظة صامتة؛ تعديل الصياغة والصعوبة.
3. محرر قضايا في الاستوديو + معاينة.
4. قضايا إضافية (مكتبة الحالة `sample_case_001` في مجلد البحث مرشحة للتحويل).
5. مخزن معدّل مشترك + استرجاع كلمة مرور + تشديد CSP.
6. ربط مزوّد توليدي اختياري خلف `guardGenerated` بعد مراجعة قانونية.
7. أصول بصرية وصوتية أصلية.

## ملاحظات للاستئناف
الأوامر: `npm run setup && npm run migrate && npm run seed`. الأدلة تُضاف عبر ملفات `content/cases/*` ثم `npm run seed` (يحدّث المسودات فقط، لا يمسّ المعتمد/المنشور). مولّدا القضيتين (Python) في `tools/generators/` (`python3 -I tools/generators/gen_c001.py content/cases`)؛ أي تعديل يدوي على JSON قد يُكتب فوقه إن أعيد التوليد.
