# سجل القرارات

| # | القرار | السبب | البديل المرفوض |
|---|---|---|---|
| D1 | الحقيقة خادمية والحوار مغلق العالم مكتوب سلفاً | منع التسرّب والهلوسة وضمان العدالة | حوار توليدي حي |
| D2 | ملفات القضية ثلاثة (core/ui/scoring) | فصل ما يُرسل عن مفاتيح التقييم | ملف واحد مع تصفية |
| D3 | وضع الجهاز برمز موقّع للضيوف وللقاصرين | لا حسابات للقاصرين ولا تخزين خادمي | تسجيل إجباري |
| D4 | الحسابات 18+ فقط حالياً | تقليل مخاطر بيانات القاصرين | موافقة وليّ الأمر (غير جاهزة) |
| D5 | تلميح دخول واحد، بلا عدّادات خسارة، مع وضع هادئ | التشويق دون استغلال القلق | سلاسل أيام وإشعارات ذنب |
| D6 | أفعال مرآة `ask_*` مخفية | تمكين مدقّق المكتبة الساكن من رؤية فتح الحوار | تعديل المدقّق |
| D7 | اتفاقية «لا مجرم»: `culprit_ids` لمن تسبّب بحدث غير مقصود | تعليم بلا شيطنة؛ تتوافق مع المخطط | حقل جديد |
| D8 | نسبة «ترجيح» لا «احتمال» | الدقة الاحتمالية؛ بوابة مصطلحات المكتبة | «احتمال» |
| D9 | الدرجات «مبدئية»؛ الحجة المكتوبة لا تُقيَّم آلياً | لا مكافأة للبلاغة؛ مراجعة بشرية | تصحيح آلي للنص |
| D10 | ترتيب الأدلة بالاكتساب وخلط الشخصيات والفرضيات حتمياً | منع تسرّب الموقع | ترتيب الملف |
| D11 | القضايا «تجريبية» ما لم تكتمل بوابات المراجعة السبع (`ATHAR_ALLOW_PREVIEW`) | الصدق بشأن غياب الخبراء | اعتبارها منشورة |
| D12 | اسم «أثر/ATHAR» اسم عمل مؤقت | تصادم أسماء رُصد؛ لم يُجرَ تدقيق علامات تجارية | اعتماد الاسم نهائياً |
| D13 | خطوط Fontsource محلية، بلا CDN | الخصوصية وضعف الاتصال | Google Fonts |
| D14 | libSQL ملفي بلا ORM | بساطة التشغيل المحلي وقابلية الترحيل إلى Turso | Postgres |
| D15 | الحكم على التعلّم عبر اختبار نقل قصير بعد كل قضية | قياس انتقال لا حفظ | إعادة اختبار نفس القضية |
