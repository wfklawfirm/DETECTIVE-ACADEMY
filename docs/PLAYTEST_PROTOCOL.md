# بروتوكول تجربة المتعلمين (نسخة أولية)

**الهدف:** معرفة هل يفهم المتعلمون القضيتين، وأين يتعثرون، وهل المهارة تنتقل. **لا نقيس ذكاءهم ولا نسوّق نتائج هذه الجلسات كدليل أثر.**

## قبل الجلسة
- 8–15 مشاركاً (16–22 سنة)، موافقة كتابية؛ للقاصرين موافقة ولي الأمر. لا جمع أسماء مع الملاحظات.
- جهاز جوال وجهاز حاسوب. المراقب لا يشرح ولا يلمّح.

## أثناء الجلسة (40–60 دقيقة)
1. «ابدأ كما تشاء» ثم القضية التمهيدية (12 د) ثم «الرصد الأخير» (40 د).
2. فكّر بصوت عالٍ؛ المراقب يدوّن الصمت الطويل (>60 ث)، الضغط الخاطئ، الرجوع بين التبويبات.
3. لا تدخّل إلا عند توقف تام 3 دقائق (سجّل ذلك كحادثة «توقف»).

## ما يُدوَّن لكل مشارك
| البند | القيمة |
|---|---|
| وقت إكمال كل قضية | دقائق |
| هل لاحظ التعارض 21:10 مقابل 00:06؟ | نعم/لا/بعد تلميح |
| هل فهم مختبر الأزمنة؟ | نعم/جزئياً/لا |
| عدد التلميحات | |
| الاستنتاج النهائي ونسبة الترجيح | |
| ما الذي لم يفهمه في المصطلحات؟ | نص |
| هل بدا «التلميح عند الدخول» مشوقاً أم مزعجاً؟ | 1–5 + تعليق |
| هل شعر بأي ضغط أو ذنب؟ | نعم/لا |
| مهمة النقل: النسبة | |

## أسئلة ما بعد الجلسة (5 دقائق)
1. ما أوضح لحظة؟ وأكثرها إرباكاً؟
2. هل شعرت أن الحل عادل (قابل للوصول بالأدلة)؟
3. هل ستعيد اللعب غداً؟ لماذا؟
4. ما الذي كنت ستغيّره؟

## التحليل
اجمع أنماط التعثر (ليس الدرجات). كل نمط يتكرر عند ≥3 مشاركين يتحول إلى مهمة تحسين. اكتب «ما لم نختبره» بجانب كل خلاصة.
