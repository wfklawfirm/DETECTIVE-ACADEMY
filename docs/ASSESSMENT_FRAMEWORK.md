# إطار التقييم

مستوحى من التصميم المرتكز على الأدلة (Evidence-Centered Design): ماذا نريد أن نستنتج عن المتعلم؟ ما السلوك الذي يدل على ذلك؟ ما المهمة التي تُنتج السلوك؟ **لم يُجرَ أي تحقق سيكومتري أو أكاديمي**؛ كل الدرجات «مبدئية» وتُعرض هكذا للاعب.

## معايير قضية «الرصد الأخير» (وزن/آلية)
| المعيار | الوزن | الآلية |
|---|---|---|
| تصنيف المصادر | 15% | مقارنة بتصنيفات مفتاحية خادمية |
| حل تعارض الأزمنة | 25% | سلوك المختبر والخط الزمني ضمن التسامح |
| ربط الأدلة بالفرضيات | 15% | مطابقة مع `link_key` |
| معايرة الثقة وحدود الاستنتاج | 15% | نطاق الثقة المقبول + قائمة الحدود الواجبة وغير الصالحة |
| مراجعة الرأي | 10% | سجل المراجعات + أسباب تغيير الرأي الصالحة |
| استبعاد الفرضيات الخاطئة | 10% | استبعاد مرتبط بدليل «يُضعف» |
| جودة الحجة المكتوبة | 10% | **بشري فقط**؛ لا تُحتسب آلياً، والنتيجة تُعاد تطبيعها على الجزء الآلي (90%) |

## ضوابط ضد التلاعب
- لا مكافأة على الطول أو الزخرفة اللغوية؛ النص الحر لا يدخل الحساب الآلي.
- سقوف: بلا أدلة مستشهَد بها ≤ 45%؛ دون حل تعارض الأزمنة ≤ 60%؛ استنتاج خاطئ مقيّد (مقياس 0.4 + 0.6·الدرجة).
- الإسراف في الاستشهاد لا يتفوق على الاستشهاد الدقيق (اختبار آلي).
- الإجابة الصحيحة بلا عمل تُسجّل منخفضة (T07).
- تلميحات: خصم ≤ 20%.
- عدم مكافأة «لغة جسد» أو «كشف الكذب»: لا يوجد معيار كهذا، وقائمة الحدود تتضمن خيارات غير صالحة مثل «ارتباكه يدل على الكذب».

## النقل
بعد كل قضية مهمة نقل قصيرة على سياق جديد (اختيار خطوات تحقق صالحة وغير صالحة + نص حر غير مُصحَّح). نتيجتها أولية وتبلغ للاعب بوصفها كذلك.

## ما لا يُدّعى
لا يُدّعى قياس ذكاء أو كفاءة مهنية أو أثر تعليمي. توصي الخطة بتجربة تجريبية مع متعلمين ومراجعين قبل أي ادعاء.
