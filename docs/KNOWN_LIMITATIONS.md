# حدود معروفة (بصراحة)

**المحتوى**
- قضيتان فقط. الأولى تمهيدية والثانية رئيسية. لا مكتبة قضايا.
- كل المراجعات الخبيرة السبع في حالة `pending`. لم يراجع أي خبير علمي أو ثقافي أو قانوني أو تربوي أي محتوى. العناصر العلمية (توحيد التوقيت، سلسلة العهدة، أنواع المصادر) كتبتها هذه الجلسة وفق المعرفة العامة ولم تُحكَّم.
- لا اختبار مع مستخدمين حقيقيين؛ أي ادعاء عن «أثر التعلّم» غير مدعوم. تقييم الأداء مبدئي وليس قياساً نفسياً مقنّناً.
- دُمجت 12 صورة و10 مؤثرات صوتية فقط (انظر CONTENT_INTEGRATION.md)؛ بقية الصور والصوت وملفات SVG الموجودة في مجلد المستخدم؛ لا أصول بصرية نهائية في المنتج (واجهة نصية/خطية).

**التقنية**
- لا مزوّد ذكاء اصطناعي موصول. الحوار مكتوب سلفاً. السؤال الحر يُطابَق بكلمات مفتاحية وقد لا يفهم صياغات كثيرة.
- `qaCase` بالـ TypeScript تقريب لمدقّق المكتبة: لا يفرض بعد شرط دحض كل فرضية خاطئة ولا متطلبات الاكتساب؛ المرجع `check_case.py` (يتطلب Python + clingo) ويجب تشغيله يدوياً قبل النشر.
- المحدّد داخل الذاكرة؛ نسخة واحدة فقط.
- بوابة العمر ذاتية. لا تحقق بريد / 2FA.
- محرر القضايا في الاستوديو لا يتجاوز قائمة النسخ والمراجعة والنشر؛ تحرير JSON يتم عبر الملفات + `npm run seed`.
- ~~لا وضع فاتح~~ — **✓ مكتمل**: زر تبديل الوضع الفاتح/الداكن/التلقائي في الشريط الجانبي والترويسة.
- لا قارئ شاشة مُختبر يدوياً (فحص axe آلي فقط)، لا اختبار على أجهزة حقيقية.
- ~~الأكاديمية: التقدّم في دروسها غير محفوظ~~ — **✓ مكتمل**: يُحفظ التقدم في جدول `lesson_progress`، ويظهر مؤشر ✓ في قائمة الدروس.
- ~~لا استرجاع كلمة مرور~~ — **✓ مكتمل**: `/forgot` و `/reset` مع رابط dev_token في التطوير.
- ~~الاستوديو: لا محرر مباشر للغلاف~~ — **✓ مكتمل**: محرر inline في `/studio/editor/[caseId]` يحفظ تلقائياً.
- لا ترجمة إنجليزية؛ الواجهة عربية فقط.

**قانوني/تجاري**
- لم يُجرَ فحص علامة تجارية لاسم «أثر/ATHAR». لا شروط استخدام نهائية ولا مراجعة قانونية للخصوصية بحسب بلد.
- لا ادعاء جاهزية تجارية.

**تبعيات (npm audit، 2026-10-27)**
- رُقّيت `zod` إلى 4.6.7 و`ajv` إلى 8.20.0 و`vitest` إلى 3.2.7 لسدّ ثغرات معلنة.
- يبقى 3 تنبيهات في سلسلة أدوات الاختبار فقط (`vitest/@vitest/mocker/tinypool`)، إصلاحها يتطلب ترقية major إلى vitest 4. لا تدخل في بناء الإنتاج؛ لا تشغّل واجهة vitest UI ولا ملفات اختبار غير موثوقة.
- تحذير `allow-scripts` الخاص بـ esbuild في npm الحديث غير مؤثر على التشغيل (جُرّب على Windows).
